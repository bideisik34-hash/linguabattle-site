run

verbo/rʌn/ 🔊 ouvir

run é um dos verbos ingleses com mais significados. O núcleo é «correr», mas vai de gerir a fluir. Irregular: run → ran → run.

📖 Significados

1correr
"I run every morning." — (correr)
2gerir, administrar (negócio)
"She runs a small café." — (gerir)
3funcionar (máquina/programa)
"The app runs on any phone." — (funcionar)
4correr, fluir (água)
"Don't leave the water running." — (fluir)
5candidatar-se (eleição)
"He's running for president." — (ser candidato)
6durar (duração)
"The show runs for two hours." — (durar)
